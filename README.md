# Payday Bill Planner Demo

Interactive public sample of the Payday Bill Planner. The demo uses example data and resets when the page is refreshed.

The paid buyer edition is not included in this repository.

## Features shown

- Biweekly payday planning
- Safe to Spend calculation
- Bills, income, and expense tracking
- Mobile-friendly monthly calendar
- Bill search and paid status

## GitHub Pages

This repository is a static website. Publish it from the `main` branch and the repository root in **Settings → Pages**.
